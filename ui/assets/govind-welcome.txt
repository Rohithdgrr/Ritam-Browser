GOVIND BROWSER — WELCOME KIT
============================

You downloaded the Govind welcome kit. Nice.

WHAT GOVIND IS
--------------
A fast, calm, local-first browser. Your history, bookmarks, notes and
downloads live on this device — never on a Govind server, because there
isn't one. No telemetry, no account, no sync upsell.

THE ZEN INTERFACE
-----------------
- Vertical tabs live in the left sidebar, grouped into Workspaces.
- Ctrl+T opens a tab, Ctrl+W closes it, Ctrl+K opens the command
  palette, Ctrl+L jumps to the address bar.
- Right-click nothing. Everything is visible or one shortcut away.

A FEW PROMISES
--------------
1. Your data stays here unless you move it.
2. Buttons always do what they say they do.
3. If a feature can't be built honestly yet, it ships as a documented
   limitation — not as a fake button.

BUILD GOVIND YOURSELF
---------------------
See README.md in the repository: npm install, then
  npm run tauri build
Requires the Rust toolchain and the WebView2 runtime (evergreen on
Windows 10 1803+ / Windows 11).
